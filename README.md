> 《绝地潜兵 2》(HELLDIVERS 2) 非官方中文随机装备挑战选择器

一键随机生成你的完整配装，并内置装备图鉴、敌人档案与任务档案。原生 HTML / CSS / JavaScript，无框架、无构建、无后端，开箱即用。

## 功能速览

- 🎲 **随机部署**：主武器 / 次要武器 / 投掷物 / 4 项战略配备 + 可选强化剂；支持背包与支援武器限制、战备权重、敌对阵营指派。
- 📋 **军备库**：按战争债券启用/排除装备，搜索、类型过滤、本地保存与链接分享。
- 📚 **装备图鉴**：200 余件装备的中文名、官方说明、用途化参数与伤害档案。
- 👾 **敌人档案**：82 个敌人（含亚阵营变体），生命值 / 护甲等级 / 弱点 / 战场识别速查。
- 🗺️ **任务档案**：64 个主任务（虫族 / 机器人 / 光能者 / 通用），难度范围、目标与难度差异。

## 使用

**网页版**：直接打开 `index.html`，或起一个本地静态服务器：

```powershell
py -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

**Windows 单文件版**：到 [Releases](../../releases) 下载 `SuperEarthArsenal.exe`，双击即可运行（需 Windows 10/11 x64 与 Edge WebView2 Runtime）。
