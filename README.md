# 超级地球随机军备终端

一个《HELLDIVERS 2》非官方中文随机装备挑战选择器。无需构建工具或后端服务。

## 使用

直接打开 `index.html` 即可。若浏览器限制本地脚本，可在此目录启动任意静态文件服务器，例如：

```powershell
py -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

当前界面按桌面终端设计，固定使用至少 1180px 的布局宽度，不再提供手机专用重排。手机浏览器会显示缩放后的桌面页面。桌面主工作区固定在视口内，不出现页面级上下滚动；装备数量较多时只在军备库右侧装备列表内部滚动。

## Windows 桌面版

可直接运行单文件桌面程序 [SuperEarthArsenal.exe](D:/AgentWorkZone/project4/desktop-app/dist/SuperEarthArsenal.exe)。它会打开独立的 Windows GUI 窗口，不显示浏览器地址栏或标签页，也不会启动系统浏览器。EXE 内含当前页面和实际使用的装备/敌人图片，用户无需安装 Python、Node.js 或项目依赖。

目标机器需要 Windows 10/11 x64 及 Microsoft Edge WebView2 Runtime。多数 Windows 10/11 设备已经具备该运行时；若缺失，需先安装 Microsoft 官方 WebView2 Runtime。应用仅在运行时监听本机 `127.0.0.1:41735`，关闭窗口即释放该端口；本地配置保存于 `%LOCALAPPDATA%/SuperEarthArsenal`。

桌面版的构建、资源清单测试与复现说明位于 [desktop-app/README.md](D:/AgentWorkZone/project4/desktop-app/README.md)。构建脚本只重建 `desktop-app/bundle`、`desktop-app/build` 和 `desktop-app/dist`，不会删除、覆盖或改动项目原有图片。

## 功能

- 固定生成主武器、次要武器、投掷物、4 项战略配备，以及可选强化剂。
- 随机部署结果会在每张装备卡中显示对应的本地装备图片；战略配备图标使用更高的固定可视区和带内边距的完整缩放，不会裁掉图标边缘。
- 可按战争债券整组启用/排除，也可单独启用/排除每件装备。
- 军备库左侧按顺序显示“全部”和所有战争债券名称；点击“全部”显示全部装备，点击具体债券后右侧只显示该债券内容。搜索、类型和“只看已启用”筛选会叠加在当前债券范围上。
- 可限制一套配置中最多出现一个背包或一件支援武器。
- 军备库的战略配备显示虫族、机器人、光能者三组 1–100 社区参考分；随机部署会随机指派一个敌对阵营，并在四项战略配备上显示该阵营的适配分。评分只用于任务参考，不改变随机概率。
- 设置保存在浏览器本地，并可通过链接分享当前装备池配置。
- 已公布但未发布的战争债券会显示在档案中，但程序不会将其加入随机池。
- 所有装备同时显示中文名称和原始英文名称/型号。
- “装备图鉴”收录 199 张本地装备图片，可按名称、战争债券和用途分类筛选。常规装备分为主武器、副武器、手雷、强化剂；红色战备分为轨道/飞鹰；蓝色战备分为仅三号位、仅背包、三号位与背包组合、载具；绿色战备分为炮塔与自动部署、需要角色操控。
- “敌人”“装备图鉴”“资料与译名”按此顺序排列在页面右侧的竖向入口列；顶部主标签和主页面只保留随机部署与军备库。
- 199 件装备均附可核实的官方军械库说明或官方 PlayStation Blog 发布说明，并明确标记说明来源。
- 装备详情按实际用途显示字段：枪械显示弹药与伤害，爆炸物显示爆炸范围，护盾显示容量与恢复，战略配备显示呼叫/冷却/次数，载具和岗哨显示耐久与部署参数。
- 详情直接在所选装备卡片下方展开，不再使用侧边抽屉。
- 装备图鉴的官方说明以中文译文显示，英文原文仍保留在生成数据中用于来源核对。
- 结构化资料尚未覆盖的具体字段会留空，不使用其他装备的模板或推测数值补全。

## 数据口径

数据更新至 2026-08-08，共收录 199 件可配置的游戏性装备。资料主要交叉参考 Helldivers Wiki、PlayStation Blog 及其繁体中文页面。官方中文资料存在时优先采用；没有公开官方译名的条目为语义翻译，英文原名保留用于核对。

图片保存在 `assets/equipment/`，依照 `primary`、`secondary`、`throwable`、`stratagem` 和 `booster` 分类。`equipment-details.js` 由 `scripts/collect-wiki-data.mjs` 根据公开结构化数据生成，包含官方说明、武器攻击档案、部署参数、护盾参数和本地图片映射，可在游戏更新后重新运行。

### 图片刷新与保留策略

图片专用脚本 `scripts/refresh-images.mjs` 会从 Helldivers Wiki MediaWiki API 查询页面实际引用的文件，并将新资源按运行批次写入 `assets/refreshed-images/<run-id>/equipment/<type>/` 与 `assets/refreshed-images/<run-id>/enemies/<faction>/`。本次已核验 162 件装备和 51 个敌人的新图；另有 37 件战略配备没有足够可靠的文件名匹配，页面继续使用原有已确认图片。

运行示例：

```powershell
node scripts/refresh-images.mjs YYYY-MM-DD
```

每批目录中的 `manifest.json` 记录来源页面、Wiki 文件标题、下载 URL、MIME、字节数和 SHA-256。脚本只使用独立目录和排他创建（`wx`）：不会删除、清空或覆盖 `assets/equipment/`、既有刷新批次或同批次已有的不同文件。确认后的映射由生成文件 `refreshed-images.js` 加载；缺少可靠新图时不会用通用背景或相似条目替代。

## 敌人档案

页面右侧常驻“敌人”“任务”“装备图鉴”“资料与译名”四个平行四边形入口，鼠标悬停或键盘聚焦时会按红、紫、蓝、绿四种档案色高亮。四个入口都使用相同的右向左扩张动画：档案舞台占据约八分之七宽度，原主页面隐藏并在左侧保留固定于视口、写有“超级地球”的平行四边形返回面板。敌人放大详情只覆盖右侧敌人舞台；图鉴与资料共用独立的可滚动档案舞台。ESC 或左侧“超级地球”面板可以返回进入前的随机部署或军备库，敌人页右上角关闭按钮也可以返回。

档案按虫族、机器人和光能者分组，共收录 82 个敌人条目（含亚阵营变体），各阵营内按护甲等级从低到高排序，卡片右上角显示护甲等级。各阵营内再按亚阵营分组显示：虫族有掠食者菌株、破裂菌株、孢子爆发菌株；机器人有焚化军团、喷射旅、义体军团（含噪轰引擎）；光能者有投票抢夺者、强占者。列表使用竖直封面卡，只显示敌人图片和名称；点击卡片后会放大图片并展示生命值、护甲等级、部位弱点、战场识别说明和 Wiki 来源。详情支持关闭按钮、ESC 和焦点恢复，面板继续支持阵营切换和搜索。敌人图片失败时只显示纯色“图像暂不可用”状态，不再叠加抽象背景图；图片透明边界不同的条目使用独立缩放与纵向位置校正。

敌人图片使用 Helldivers Wiki 页面实际引用的本地化文件，刷新后的文件按阵营保存在 `assets/refreshed-images/2026-08-08-matched/enemies/`，映射由 `refreshed-images.js` 覆盖到 `ENEMY_DATA`。敌人生命值取自 Wiki 的 `Enemies` Cargo 表（`health` 字段），多部位敌人按主体/炮塔等拆分标注，随难度变化的值标注对应难度段；敌人数据的更新时间为 2026-08-08，部分敌人存在形态、难度或版本差异，无法确认统一数值的字段明确显示为“待核实”。

## 任务档案

页面右侧「任务」入口（位于「敌人」之后）打开任务档案。任务按虫族、机器人、光能者三阵营分组，另加一组「通用」（任意阵营的星球都可能出现的主任务），共收录 64 个主任务。每个任务标注难度范围、时限、目标说明与「难度差异」说明；档案顶部提供 1–10 级难度梯度参考，汇总敌军数量与种类、巡逻频率、行动修正（难度 5 起 1 项、难度 8 起第 2 项）、据点规模与可选目标数量随难度的变化。

任务图标由 `scripts/collect-mission-data.mjs` 从 Helldivers Wiki 下载并保存在 `assets/missions/`；任务数据手工维护在 `mission-data.js`（中文名为语义翻译，英文原名保留用于核对）。部分任务为事件型或仅出现在极窄的难度区间，档案会如实标注其难度范围。

装备中文说明保存在生成文件 `equipment-descriptions-zh.js`，由 `scripts/generate-chinese-descriptions.mjs` 根据 `equipment-details.js` 的英文来源文本生成并校验 199/199 覆盖；界面显示经过术语统一和人工抽查的中文版本。

战略配备评分保存在手写文件 `stratagem-ratings.js`。它读取 `equipment-details.js` 的伤害、穿甲、爆炸范围、持续状态和控制字段，结合公开社区攻略中对虫族群体压制、机器人高穿甲、光能者电弧/光束等用途的常见评价，计算相对分数。分数不是官方平衡评级，也不代表固定击杀时间；游戏更新后应重新审查评分口径。
