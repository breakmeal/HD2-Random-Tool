# 固定桌面军备库布局 ExecPlan

状态：Complete
创建日期：2026-08-08
最后更新：2026-08-08 20:00

## Purpose / Goal

将桌面主界面收纳到固定视口内，不让浏览器或桌面窗口出现页面级纵向滚轮；重做军备库为左侧战争债券筛选栏和右侧当前债券装备列表，便于在有限空间内快速查看和管理装备。

## Requirements

- [x] 随机部署和军备库主页面在不小于 1180px 的桌面视口内不出现页面级上下滚动。
- [x] 主页面的重要内容在初始视图即可见；密集装备列表只允许在自身面板内滚动。
- [x] 军备库左栏顶部包含“全部”，其后按现有 `WARBONDS` 顺序显示战争债券名称。
- [x] 点击一个债券后，右侧只显示该债券的装备；“全部”显示过滤后的全部装备。
- [x] 保留整债券开关、单件装备开关、搜索、类型筛选、仅看已启用和未发布内容的现有规则。
- [x] 不修改生成装备数据、图片资源、发布状态或随机池规则，并重建桌面 EXE。

## Current State

- `index.html` 的主页面含较高 hero、两个主标签和两个面板；`body` 尚允许普通页面滚动。
- `app.js` 的 `state.open` 和 `renderArmory()` 把每个债券渲染为可展开的 `.warbond` 卡片，筛选后可同时展开多个债券。
- `styles.css` 定义基础军备库组件，`interface-refresh.css` 为当前桌面终端外观提供覆盖层。
- 桌面打包位于 `desktop-app/`；构建脚本会复制这些源文件并生成单文件 `SuperEarthArsenal.exe`。

## Implementation Plan

1. 在 `index.html` 将军备库内容容器拆为债券导航列和装备内容列，保留既有筛选和批量操作按钮。
2. 在 `app.js` 用单一 `filters.warbond` 取代展开状态；渲染左栏和当前装备列表，并让事件委托支持债券选择、债券总开关和单件开关。
3. 在 `interface-refresh.css` 添加固定视口桌面布局：压缩主标题与部署卡、限制主区域高度、禁用页面级滚动，并只让军备库的两列内部滚动。
4. 更新 README、AGENTS.md 和本计划，记录固定桌面工作区与军备库导航行为；重建 EXE。
5. 在 1440x900 桌面视口验证无页面滚动、随机部署、债券选择、筛选组合、开关状态和 EXE 资源包。

## Decisions

- 2026-08-08：页面外层使用固定视口，装备过多时只在军备库内部列表滚动。
  - 原因：全部 199 件装备无法在物理视口中同时铺开；用户要求的是主页面无滚轮和内容直接可达，而不是删除或缩小装备内容。
  - 影响：页面级 `window` 不再滚动，军备库右侧列表使用独立滚动条。
- 2026-08-08：债券选择使用“全部 + 单选债券”的筛选模型，不再使用多债券展开状态。
  - 原因：符合左侧名称列点击后只显示当前债券的交互要求。
  - 影响：搜索、类型和已启用筛选继续叠加在当前债券范围上。

## Discoveries

- `WARBONDS` 已按数据源顺序提供，适合作为左侧导航的显示顺序；不需要改动 `data.js`。
- 军备库的切换和保存逻辑已集中在 `toggleWarbond()`、`toggleGear()` 与 `renderArmory()`，可在不触碰随机逻辑的前提下替换显示层。
- 固定布局初版中右侧列表因父容器未声明网格布局而撑高；浏览器回归发现后已将 `.armory-catalog` 设为固定网格容器，确认列表 `clientHeight` 为 467、`scrollHeight` 为 5511，页面本身仍为 900 高。

## Risks / Open Questions

- 固定视口对较矮的桌面窗口会压缩展示空间。缓解：桌面 EXE 已设定最小 1180x720；对该范围保留可用的紧凑卡片和内部滚动。非阻塞。
- 页面级无滚动会影响旧的“返回顶部”链接。缓解：保留其焦点行为，但不再依赖页面滚动位置。非阻塞。
