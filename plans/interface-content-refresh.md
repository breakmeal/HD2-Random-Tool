状态：Complete
创建日期：2026-08-08

## Purpose / Goal

把敌人档案改成适合浏览和逐项查看的竖向封面卡；点击敌人后放大并显示详细资料。随机部署结果同步展示装备图片。装备图鉴的官方英文说明全部提供中文译文，不再把英文正文作为主要描述内容。

## Requirements

- [x] 敌人列表使用竖直卡片，仅突出图片与名称。
- [x] 点击敌人后放大展示图片、生命值、弱点、战场识别和来源，支持关闭、ESC 与焦点恢复。
- [x] 根据敌人图片实际透明边界调整部分图片的缩放和纵向位置，不对所有图片强制同一位置。
- [x] 删除敌人卡片和敌人舞台背后的抽象背景图；图片失败时使用纯色占位，不再回退到该背景。
- [x] 随机部署结果中的主武器、次要武器、投掷物、强化剂和战略配备均显示对应图片。
- [x] 199 件装备的官方说明均有合适中文译文；生成文件 `equipment-details.js` 未手工修改。
- [x] 保持未发布装备不进入随机池、装备 ID 与原有图片资源不变。
- [x] README、AGENTS.md 和相关计划同步更新。

## Current State

- `enemy-dossier.js` 在每张卡片中常驻渲染图片、名称、生命值、弱点、战场识别和来源，没有独立选中状态。
- `enemy-dossier.css` 使用两列横向信息卡，`.enemy-card-visual`、`.enemy-overlay::before`、`.enemy-portal` 和 `.earth-stage-return` 都引用 `assets/ui/enemy-terminal-bg.png`。
- 51 张本地敌人 PNG 的主体尺寸和透明留白不一致，当前统一使用 `width/height: 88%` 与 `object-fit: contain`。
- `app.js::renderLoadout()` 的随机结果卡只显示名称与战争债券，没有读取 `EQUIPMENT_DETAILS[item.id].image`。
- `equipment-details.js` 是采集脚本生成文件；199 件装备都有 `officialDescription`，当前全部为英文。`codex-v2.js::inlineDetailHtml()` 直接以 `lang="en"` 渲染该字段。
- 页面脚本顺序为 `data.js` → `equipment-details.js` → `enemy-data.js` → `refreshed-images.js` → `app.js` → `codex-v2.js` → `enemy-dossier.js`。

## Implementation Plan

1. 分析敌人 PNG 的画布和透明主体边界，为明显偏下、偏小或横向过宽的条目建立少量视图覆盖参数。
2. 修改 `enemy-dossier.js` 与 `enemy-dossier.css`：列表改为竖卡；新增焦点详情层、键盘与焦点管理；移除敌人区域的背景图引用并使用纯色失败状态。
3. 修改 `app.js` 与 `styles.css`，在随机结果卡中读取最终图片映射并为不同装备类型提供稳定图片区域。
4. 新增手写中文说明覆盖数据和生成/校验脚本；`codex-v2.js` 优先显示中文译文，保留英文原文只作为可追溯数据而不直接展示。
5. 更新 README、AGENTS.md 和计划，运行语法、数据、翻译覆盖率、资源路径与浏览器交互验证。

## Decisions

- 2026-08-08 — 决定：中文说明使用独立覆盖文件，不直接编辑 `equipment-details.js`。
  - 原因：后者是采集脚本生成文件，直接修改会在下次采集时丢失。
  - 影响：脚本加载顺序需要增加中文说明文件，校验必须保证其与装备 ID 一一对应。
- 2026-08-08 — 决定：敌人列表卡与放大详情使用同一份 `ENEMY_DATA`，只在视图层增加焦点状态。
  - 原因：数据已经完整，本次是展示方式变化，不应复制敌人资料。
  - 影响：阵营切换和搜索时需关闭不再可见的详情。
- 2026-08-08 — 决定：保留英文说明字段，新增独立中文覆盖映射。
  - 原因：英文原文是来源核对依据，且 `equipment-details.js` 由采集脚本生成。
  - 影响：`codex-v2.js` 只显示中文覆盖，重新生成详情不会丢失原文。
