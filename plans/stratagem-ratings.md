## Purpose / Goal

为军备库中的 89 件战略配备增加虫族、机器人、光能者三组相对强度分，并让每次随机部署指派一个敌对阵营、显示四项战略配备对该阵营的适配分。

## Requirements

- [x] 每件战略配备都有 1–100 的三阵营社区参考分。
- [x] 分数使用现有 Wiki 结构化攻击、穿甲、范围、状态和控制数据，并保留非官方说明。
- [x] 军备库显示三阵营分数，随机部署显示敌情指派和对应战略配备分数。
- [x] 评分不改变随机概率、启用状态、发布状态或装备 ID。
- [x] 同步 README、SOURCES.md、AGENTS.md 和桌面打包文件。

## Current State

- `data.js` 提供 89 件 `stratagem` 和用途标签，但没有评分字段。
- `equipment-details.js` 是生成文件，包含战略配备攻击的标准/耐久伤害、穿甲等级、爆炸半径、状态元素、控制参数和部分部署字段。
- `app.js` 负责随机部署卡和军备库渲染；`index.html` 的脚本顺序可加入评分派生层。
- 现有来源文档已记录 Helldivers Wiki 的战略配备攻击数据 URL；社区攻略只能作为适配趋势参考，不能替代结构化数值。

## Decisions

- 2026-08-08：评分采用 1–100 相对值，不写入生成详情文件。
  - 原因：保持采集生成边界，并明确社区参考值不是官方平衡数据。
  - 影响：数据更新后只需审查评分层公式，随机池和装备 ID 不变。
- 2026-08-08：每次随机部署随机选择虫族、机器人或光能者作为任务目标。
  - 原因：让用户理解同一战备面对不同敌人的价值差异。
  - 影响：随机结果仍只决定装备，敌情指派只影响显示的适配分。

## Discoveries

- 火焰喷射器结构化数据带有火焰状态和穿甲等级，模型自然产生虫族高于机器人的适配结果；示例为虫族 91、机器人 78、光能者 86。
- 背包、护盾、载具等没有攻击档案的战备仍会得到保守中间分，不伪造不存在的伤害值。

## Risks / Open Questions

- 游戏补丁或社区策略变化会使相对分过时。缓解：界面和文档明确日期与非官方性质；后续可按版本更新评分公式。非阻塞。
- 公开社区意见不是单一权威来源。缓解：结构化 Wiki 数据负责基础分，社区内容只用于阵营适配方向。非阻塞。
