## Current State

- `index.html` 的主 `<main>` 仍直接包含 `roulettePanel`、`armoryPanel`、`codexPanel`、`intelPanel`；右侧入口顺序为图鉴、资料、敌人。
- `app.js::activatePanel()` 只切换 `.panel.active`，图鉴和资料仍在主页面原位显示，没有独立扩张舞台。
- `enemy-dossier.css` 已实现敌人模式下 12.5% 左栏与 87.5% 右侧舞台动画，可抽取为档案舞台共同行为。
- 随机结果图片使用 `.loadout-visual` 的 126px 固定高度和 `overflow:hidden`；战略配备图片又被统一限制为 72% 宽高，无法针对不同透明边界充分利用可视区域。
- `styles.css`、`codex.css`、`enemy-dossier.css` 和 `interface-refresh.css` 均包含手机断点；当前任务将通过固定桌面布局视口与移除新增手机专用覆盖，停止提供手机布局承诺。

## Implementation Plan

1. 在 `index.html` 添加独立档案舞台容器，调整右侧入口顺序，并把移动端 viewport 改为固定桌面宽度。
2. 在 `app.js` 初始化时把图鉴/资料面板移入档案舞台，扩展 `activatePanel()`、返回入口和 ESC 行为，使主页面与档案舞台职责分离。
3. 在 `interface-refresh.css` 实现档案舞台的宽度动画、桌面内容布局和战略配备结果图片完整显示；在 `enemy-dossier.css` 复用档案模式的左栏动画。
4. 实际随机多轮抽查四项战略配备图片，验证敌人/图鉴/资料顺序、三个右侧舞台和返回交互。
5. 更新 README、AGENTS.md 与本计划，执行语法和数据完整性校验。

## Decisions

- 2026-08-08 — 决定：图鉴与资料共用一个独立 `archive-overlay`，内部切换原有面板。
  - 原因：两者互斥显示且动画、宽度、返回行为完全一致，共用舞台可避免复制状态与过渡逻辑。
  - 影响：图鉴和资料节点在初始化时从主 `<main>` 移入档案舞台，事件绑定继续使用全局 ID，不改变现有功能。
- 2026-08-08 — 决定：停止手机适配采用固定 1180px 桌面布局视口，不删除项目历史上的全部响应式规则。
  - 原因：完整删除四个样式文件中的既有断点会产生大范围无关重排；固定桌面视口可明确停止手机重排，同时保留未来恢复适配的基础。
  - 影响：窄屏设备显示可缩放的桌面终端，不再承诺原生手机操作布局。

## Discoveries

- 图鉴与资料的 DOM 事件均通过文档级 ID 查询或容器事件委托绑定，移动节点不会破坏脚本依赖。
- 随机战略配备图片并非缺失，而是展示层把所有战略配备统一缩到 72% 并放入 126px 高的裁切容器；本任务只调整展示层，不触碰图片文件。
- 首次尝试扩大图片并允许容器溢出后，SVG 的固有 1:1 最小尺寸使图标越过 142px 区域并遮住名称。修正为同时设置 `min/max-width`、`min/max-height` 和 `object-fit:contain`，在更高但仍裁切的稳定区域内完整缩放。
- 浏览器对失焦后的 `body.press('Escape')` 拒绝派发按键；改用页面级键盘输入后，ESC 成功关闭资料舞台。该失败只影响测试方式，不影响页面实现。
- 尝试在 390px 临时视口读取布局指标时，页面重载后的选择器等待超时；随后已重置浏览器视口。手机布局已明确移出本次支持范围，固定 `width=1180` viewport、1180px 最小宽度和手机覆盖规则移除通过静态检查确认。

## Risks / Open Questions

- 图鉴内容很长，档案舞台必须自行滚动，不能依赖主文档滚动。缓解：独立 drawer 使用 `height:100%` 与 `overflow:auto`。非阻塞。
- `earthStageReturn` 当前由敌人脚本独占点击处理。缓解：应用脚本只在 `archive-mode` 时处理同一按钮，敌人脚本在敌人未打开时会直接返回。非阻塞。
